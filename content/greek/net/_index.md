## Πώς να διαγράψετε σελίδες PDF βήμα προς βήμα

Το `Redactor` είναι η κεντρική κλάση στο GroupDocs.Redaction που φορτώνει, τροποποιεί και αποθηκεύει έγγραφα. Η μέθοδος `RemovePages` αφαιρεί τις καθορισμένες σελίδες από το φορτωμένο έγγραφο.

Φορτώστε το PDF, ορίστε τις σελίδες που θέλετε να αφαιρέσετε, εφαρμόστε τη διαγραφή και αποθηκεύστε το αποτέλεσμα. Η παρακάτω άμεση απάντηση εξηγεί το βασικό μοτίβο:

Φορτώστε το στόχο PDF με `Redactor.Load(streamOrPath)`, καλέστε `Redactor.RemovePages(pageNumbers)` για να διαγράψετε τις ανεπιθύμητες σελίδες και, τέλος, εκτελέστε `Redactor.Save(outputPath)` – αυτή η τριβήμα ροή διαγράφει σελίδες σε λιγότερο από ένα δευτερόλεπτο για τα περισσότερα έγγραφα.

### Βήμα 1: φόρτωση του PDF
Μπορείτε να ανοίξετε ένα αρχείο από δίσκο, μνήμη (memory stream) ή απομακρυσμένη πηγή. Το API δέχεται τόσο συμβολοσειρά διαδρομής αρχείου όσο και αντικείμενο `Stream`, κάτι που είναι ιδανικό για web services που λαμβάνουν ανεβάσματα.

### Βήμα 2: ορισμός των σελίδων προς διαγραφή
Περάστε μια λίστα με μηδενική βάση (zero‑based) δείκτες σελίδων ή μια συμβολοσειρά εύρους όπως `"1-3,5"` στη μέθοδο `RemovePages`. Η βιβλιοθήκη επικυρώνει το εύρος και ρίχνει σαφή εξαίρεση αν μια σελίδα δεν υπάρχει.

### Βήμα 3: αποθήκευση του καθαρισμένου εγγράφου
Καλέστε `Save` με τη μορφή εξόδου που επιθυμείτε. Μπορείτε να διατηρήσετε το αρχικό PDF, να εξάγετε σε rasterized PDF ή να στείλετε το αποτέλεσμα απευθείας ως ροή στην απόκριση του πελάτη.

## Συνηθισμένα προβλήματα και λύσεις
- **Πρόβλημα:** Η διαγραφή φαίνεται να λειτουργεί αλλά το αρχικό κείμενο παραμένει αναζητήσιμο.  
  **Λύση:** Ενεργοποιήστε τη rasterization (`Redactor.Rasterize = true`) πριν την αποθήκευση· αυτό μετατρέπει τη σελίδα σε εικόνα, αφαιρώντας τα κρυφά επίπεδα κειμένου.  

- **Πρόβλημα:** Μεγάλα PDF προκαλούν εξαιρέσεις OutOfMemory.  
  **Λύση:** Χρησιμοποιήστε `Redactor.Load(stream, loadOptions => loadOptions.EnableMemoryOptimization = true)` για επεξεργασία του αρχείου σε τμήματα.  

- **Πρόβλημα:** Οι σχολιασμοί δεν αφαιρούνται.  
  **Λύση:** Καλέστε `Redactor.RemoveAnnotations()` μετά τη φόρτωση του εγγράφου· αυτή η μέθοδος αφαιρεί σχόλια, επισήμανση και πεδία φόρμας.

## Συχνές ερωτήσεις

**Ε: Είναι δυνατόν να διαγράψω μόνο τα σχόλια PDF;**  
Α: Απόλυτα. Χρησιμοποιήστε `Redactor.RemoveAnnotations()` για να αφαιρέσετε όλα τα αντικείμενα σχολιασμού με μία κλήση.

**Ε: Πώς διαγράφω κελιά Excel απευθείας;**  
Α: Φορτώστε το βιβλίο εργασίας με `Redactor.LoadExcel(path)`, στη συνέχεια καλέστε `Redactor.RedactCell(sheetName, cellAddress, RedactionMode.Blackout)` και αποθηκεύστε.

Α: Ναι, μπορείτε να περάσετε οποιοδήποτε `System.IO.Stream` στη μέθοδο `Load`, κάτι που είναι ιδανικό για επεξεργασία αρχείων που ανεβάζονται μέσω ελεγκτών ASP.NET Core.
