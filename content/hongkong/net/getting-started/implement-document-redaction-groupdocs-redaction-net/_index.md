# 如何以程式方式使用 GroupDocs.Redaction .NET 建立已編輯的 PDF

在當今的數位時代，**以程式方式建立已編輯的 PDF** 是任何處理個人或機密資料的應用程式必備的功能。無論您需要遵守 GDPR、HIPAA 或內部安全政策，在分享 PDF 前編輯敏感資訊都能保護隱私並降低法律風險。本教學將示範如何使用 **GroupDocs.Redaction for .NET** 來定位、遮蔽，最終將文件儲存為安全的 PDF。您將學會：

- 從 Word、Excel、PowerPoint 及其他支援的格式中編輯敏感資訊  
- 將已編輯的內容轉換為影像並嵌入 PDF 中  
- 為大型檔案優化效能，並將解決方案整合至現有的 .NET 專案  

在深入之前，讓我們確認您已具備所有必要的條件。

## 快速答案

- **「以程式方式建立已編輯的 PDF」是什麼意思？** 指使用程式碼自動定位並遮蔽機密資料，然後將結果儲存為 PDF。  
- **哪個函式庫負責編輯？** GroupDocs.Redaction for .NET。

## 什麼是以程式方式建立已編輯的 PDF？

以程式方式建立已編輯的 PDF 意指使用程式碼——通常透過如 GroupDocs.Redaction 的 API——在來源檔案中定位機密文字、影像或中繼資料，依照定義的規則取代或移除該內容，然後產生不再包含原始敏感資訊的新 PDF。此自動化方式確保在大量文件集合中保持一致性與合規性。

## 為何使用 GroupDocs.Redaction for .NET？

GroupDocs.Redaction 支援 **30+ 種輸入與輸出格式**，且可在不將整個檔案載入記憶體的情況下處理高達 **2 GB** 的文件，較傳統做法可減少 **30 % 記憶體使用量**。此函式庫亦內建 OCR 編輯功能，確保即使是掃描影像也能被搜尋與移除。

## 如何以程式方式建立已編輯的 PDF？

要以程式方式建立已編輯的 PDF，首先將來源文件載入 `Redactor` 實例，接著定義並套用一或多個 `Redaction` 物件以指定要移除或取代的文字或模式，最後呼叫帶有 `PdfSaveOptions` 的 `Save` 方法產生安全的 PDF 檔案。以下程式碼示範每個步驟。

### 步驟 1：初始化 Redactor

`Redactor` 是負責載入、處理與儲存文件，同時維持文件完整性的核心類別。

```csharp
using (Redactor redactor = new Redactor("YOUR_DOCUMENT_DIRECTORY\SampleDocument.docx"))
{
    // Further operations will go here.
}
```  

**為何使用 Redactor？**  
`Redactor` 類別提供結構化的文件處理方式，確保記憶體管理效能並在各種格式間產生一致的編輯結果。

### 步驟 2：套用精確片語編輯

`Redaction` 物件定義要隱藏的文字以及取代方式。

```csharp
redactor.Apply(new ExactPhraseRedaction("John Doe", new ReplacementOptions("[personal]"));
```  

**了解參數與方法**  
- `"John Doe"` – 要定位的精確片語。  
- `ReplacementOptions` – 指定佔位符（例如 `"[personal]"`）及其視覺樣式。

### 步驟 3：儲存為 PDF

`PdfSaveOptions` 控制最終 PDF 的輸出，包括影像品質與頁面範圍。

```csharp
redactor.Save(new PdfSaveOptions());
```  

**主要設定選項**  
您可以設定 `PageCount`、`ImageQuality` 與 `CompressImages` 以在檔案大小與視覺品質之間取得平衡。

## 常見問答

**Q: 如何處理大於 2 GB 的文件？**  
A: 將來源檔案依章節等邏輯分段，分別進行編輯，最後合併產生的 PDF。

**Q: 我可以自訂編輯佔位符的樣式嗎？**  
A: 可以 — `ReplacementOptions` 允許您定義佔位文字或影像的字型、顏色與透明度。

**Q: GroupDocs.Redaction 是否支援掃描 PDF 的 OCR 編輯？**  
A: 完全支援。建立 `Redactor` 時啟用 `OcrOptions` 即可偵測並編輯影像內的文字。

**Q: 是否支援批次處理？**  
A: 您可以遍歷檔案路徑集合，於平行任務中呼叫相同的編輯邏輯，以同時處理數十個檔案。
