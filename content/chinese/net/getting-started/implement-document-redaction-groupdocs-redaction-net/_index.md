# 如何使用 GroupDocs.Redaction .NET 以编程方式创建已编辑的 PDF

- 从 Word、Excel、PowerPoint 以及其他受支持的格式中编辑敏感信息  
- 将编辑后的内容转换为图像并嵌入 PDF  
- 针对大文件优化性能，并将解决方案集成到现有的 .NET 项目中

## 如何以编程方式创建已编辑的 PDF？

要以编程方式创建已编辑的 PDF，首先将源文档加载到 `Redactor` 实例中，然后定义并应用一个或多个指定要删除或替换的文本或模式的 `Redaction` 对象，最后使用 `PdfSaveOptions` 调用 `Save` 方法生成安全的 PDF 文件。以下代码演示了每一步。

### 步骤 1：初始化 Redactor
`Redactor` 是加载、处理并保存文档的核心类，同时保持文档完整性。

```csharp
using (Redactor redactor = new Redactor("YOUR_DOCUMENT_DIRECTORY\SampleDocument.docx"))
{
    // Further operations will go here.
}
```  

**为什么使用 Redactor？**  
`Redactor` 类提供了一种结构化的方式来处理文档，确保高效的内存管理并在各种格式下实现一致的编辑结果。

### 步骤 2：应用精确短语编辑
`Redaction` 对象定义了要隐藏的文本以及替换方式。

```csharp
redactor.Apply(new ExactPhraseRedaction("John Doe", new ReplacementOptions("[personal]"));
```  

**了解参数和方法**  
- `"John Doe"` – 要定位的精确短语。  
- `ReplacementOptions` – 指定占位符（例如 `"[personal]"`）以及视觉样式。

### 步骤 3：保存为 PDF
`PdfSaveOptions` 控制最终 PDF 的输出，包括图像质量和页码范围。

```csharp
redactor.Save(new PdfSaveOptions());
```  

**关键配置选项**  
您可以设置 `PageCount`、`ImageQuality` 和 `CompressImages` 来在文件大小和视觉保真度之间取得平衡。

## 常见问答

**Q: How do I handle documents larger than 2 GB?**  
A: 将源文件按逻辑章节（例如按章节）拆分，分别编辑后再合并生成最终的 PDF。

**Q: Can I customize the redaction placeholder style?**  
A: 可以——`ReplacementOptions` 允许您为占位符文本或图像定义字体、颜色和不透明度。

**Q: Does GroupDocs.Redaction support OCR for scanned PDFs?**  
A: 当然。创建 `Redactor` 时启用 `OcrOptions` 即可检测并编辑图像中的文本。

**Q: Is batch processing possible?**  
A: 可以遍历文件路径集合，在并行任务中调用相同的编辑逻辑，以同时处理数十个文件。
