## Быстрые ответы
- **Может ли GroupDocs.Redaction редактировать целые страницы PDF?** Да, вы можете удалять отдельные страницы или диапазоны страниц одним вызовом API.  
- **Поддерживает ли он удаление аннотаций PDF?** Абсолютно — аннотации, комментарии и разметка могут быть удалены за один шаг.  
- **Могу ли я редактировать ячейки Excel без конвертации в PDF?** Да, библиотека работает непосредственно с листами Excel.  
- **Поддерживается ли загрузка PDF из потока?** API принимает объекты `Stream`, позволяя обрабатывать файлы в памяти.  
- **Какие версии .NET совместимы?** .NET Framework 4.5+, .NET Core 3.1+, .NET 5/6/7.

## Что такое redaction в контексте PDF?
Редактирование (redaction) — это постоянное удаление или сокрытие конфиденциального контента из документа, так чтобы его нельзя было восстановить или просмотреть позже. В PDF‑файлах редактирование может быть направлено на текст, изображения, аннотации или целые страницы, и результатом является очищенный файл, сохраняющий оригинальное расположение элементов.

## Как замаскировать страницы PDF пошагово

Redactor — основной класс в GroupDocs.Redaction, который загружает, изменяет и сохраняет документы. RemovePages удаляет указанные страницы из загруженного документа.

Загрузите PDF, определите страницы, которые хотите удалить, примените редактирование и сохраните результат. Ниже приведён прямой ответ, объясняющий основной шаблон:

Загрузите целевой PDF с помощью `Redactor.Load(streamOrPath)`, вызовите `Redactor.RemovePages(pageNumbers)`, чтобы удалить нежелательные страницы, и, наконец, вызовите `Redactor.Save(outputPath)` — этот трёхшаговый процесс редактирует страницы менее чем за секунду для большинства документов.

### Шаг 1: загрузка PDF
Вы можете открыть файл с диска, из потоковой памяти или удалённого источника. API принимает как строку пути к файлу, так и объект `Stream`, что идеально подходит для веб‑служб, получающих загрузки.

### Шаг 2: определение страниц для редактирования
Передайте список нулевых индексов страниц или строку диапазона, например `"1-3,5"`, в метод `RemovePages`. Библиотека проверяет диапазон и бросает понятное исключение, если страница не существует.

### Шаг 3: сохранение очищенного документа
Вызовите `Save` с желаемым форматом вывода. Вы можете сохранить оригинальный PDF, экспортировать в растеризованный PDF или передать результат напрямую в ответ клиенту.

## Распространённые проблемы и решения
- **Проблема:** Редактирование, кажется, работает, но исходный текст всё ещё доступен для поиска.  
  **Решение:** Включите растеризацию (`Redactor.Rasterize = true`) перед сохранением; это преобразует страницу в изображение, удаляя скрытые текстовые слои.  

- **Проблема:** Большие PDF вызывают исключения OutOfMemory.  
  **Решение:** Используйте `Redactor.Load(stream, loadOptions => loadOptions.EnableMemoryOptimization = true)`, чтобы обрабатывать файл кусками.  

- **Проблема:** Аннотации не удаляются.  
  **Решение:** Вызовите `Redactor.RemoveAnnotations()` после загрузки документа; этот метод удаляет комментарии, выделения и поля формы.

## Часто задаваемые вопросы

**Q: Могу ли я редактировать страницы PDF, не влияя на остальное оформление документа?**  
A: Да, библиотека удаляет указанные страницы, сохраняя нумерацию страниц, закладки и перекрёстные ссылки для оставшегося содержимого.

**Q: Можно ли редактировать только аннотации PDF?**  
A: Абсолютно. Используйте `Redactor.RemoveAnnotations()`, чтобы удалить все объекты аннотаций одним вызовом.

**Q: Как напрямую редактировать ячейки Excel?**  
A: Загрузите рабочую книгу с помощью `Redactor.LoadExcel(path)`, затем вызовите `Redactor.RedactCell(sheetName, cellAddress, RedactionMode.Blackout)` и сохраните.

**Q: Поддерживает ли GroupDocs.Redaction загрузку PDF из потока?**  
A: Да, вы можете передать любой `System.IO.Stream` в метод `Load`, что идеально подходит для обработки файлов, загруженных через контроллеры ASP.NET Core.

**Q: Какая модель лицензирования рекомендуется для высокообъёмного производственного использования?**  
A: Лицензирование по метру позволяет платить за каждую операцию редактирования, эффективно масштабируя затраты при всплесках использования.
