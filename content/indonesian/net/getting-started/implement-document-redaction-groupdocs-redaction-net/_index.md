## Cara membuat PDF yang disensor secara programatis?
Untuk membuat PDF yang disensor secara programatis, pertama muat dokumen sumber ke dalam instance `Redactor`, kemudian definisikan dan terapkan satu atau lebih objek `Redaction` yang menentukan teks atau pola yang akan dihapus atau diganti, dan akhirnya panggil metode `Save` dengan `PdfSaveOptions` untuk menghasilkan file PDF yang aman. Kode berikut menggambarkan setiap langkah.

### Langkah 1: inisialisasi redactor
`Redactor` adalah kelas inti yang memuat, memproses, dan menyimpan dokumen sambil mempertahankan integritas dokumen.

```csharp
using (Redactor redactor = new Redactor("YOUR_DOCUMENT_DIRECTORY\SampleDocument.docx"))
{
    // Further operations will go here.
}
```  

**Mengapa menggunakan Redactor?**  
Kelas `Redactor` menyediakan cara terstruktur untuk menangani dokumen, memastikan manajemen memori yang efisien dan hasil penyensoran yang konsisten di semua format.

### Langkah 2: terapkan penyensoran frasa tepat
Objek `Redaction` menentukan teks apa yang akan disembunyikan dan bagaimana menggantinya.

```csharp
redactor.Apply(new ExactPhraseRedaction("John Doe", new ReplacementOptions("[personal]"));
```  

**Memahami parameter dan metode**  
- `"John Doe"` – frasa tepat yang akan ditemukan.  
- `ReplacementOptions` – menentukan placeholder (misalnya, `"[personal]"`) dan gaya visual.

### Langkah 3: simpan sebagai PDF
`PdfSaveOptions` mengontrol output PDF akhir, termasuk kualitas gambar dan rentang halaman.

```csharp
redactor.Save(new PdfSaveOptions());
```  

**Opsi konfigurasi utama**  
Anda dapat mengatur `PageCount`, `ImageQuality`, dan `CompressImages` untuk menyeimbangkan ukuran file dan kesetiaan visual.

## Masalah umum dan solusi
- **File‑path errors** – Verifikasi bahwa jalur input dan output keduanya absolut atau relatif dengan benar terhadap direktori yang menjalankan.  
- **Unsupported format** – Periksa daftar format di dokumen resmi; format Office lama mungkin perlu konversi terlebih dahulu.  
- **Memory spikes with large files** – Gunakan API asynchronous (`Redactor.RedactAsync`) dan proses dokumen dalam potongan.

## Pertanyaan yang sering diajukan
**Q: Bagaimana saya menangani dokumen yang lebih besar dari 2 GB?**  
A: Bagi file sumber menjadi bagian logis (mis., per bab) dan sensor setiap bagian secara terpisah, lalu gabungkan PDF yang dihasilkan.  

**Q: Bisakah saya menyesuaikan gaya placeholder penyensoran?**  
A: Ya—`ReplacementOptions` memungkinkan Anda menentukan font, warna, dan opasitas untuk teks atau gambar placeholder.  

**Q: Apakah GroupDocs.Redaction mendukung OCR untuk PDF yang dipindai?**  
A: Tentu saja. Aktifkan `OcrOptions` saat membuat `Redactor` untuk mendeteksi dan menyensor teks dalam gambar.  

**Q: Apakah pemrosesan batch memungkinkan?**  
A: Anda dapat melakukan loop pada koleksi jalur file dan memanggil logika penyensoran yang sama dalam tugas paralel untuk memproses puluhan file secara bersamaan.
