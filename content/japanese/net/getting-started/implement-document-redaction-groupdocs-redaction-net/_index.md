# GroupDocs.Redaction .NET を使用したプログラムによる赤字PDFの作成方法

今日のデジタル時代において、**プログラムで赤字PDFを作成する**ことは、個人情報や機密データを扱うあらゆるアプリケーションに必須の機能です。GDPR、HIPAA、あるいは社内のセキュリティポリシーに準拠する必要がある場合でも、PDF を共有する前に機密情報をマスクすることでプライバシーを保護し、法的リスクを低減できます。本チュートリアルでは、**GroupDocs.Redaction for .NET** を使用して、ドキュメント内の対象を検出・マスクし、最終的に安全な PDF として保存する方法を示します。以下を学びます。

- Word、Excel、PowerPoint、その他対応フォーマットから機密情報を赤字化  
- 赤字化したコンテンツを画像に変換し、PDF に埋め込む  
- 大容量ファイルのパフォーマンスを最適化し、既存の .NET プロジェクトに統合  

実際に作業を始める前に、必要なものがすべて揃っているか確認してください。

## クイック回答
- **「プログラムで赤字PDFを作成する」とは何ですか？** コードを使用して機密データを自動的に検出・マスクし、結果を PDF として保存することを指します。  
- **どのライブラリが赤字化を担当しますか？** GroupDocs.Redaction for .NET。  
- **開発にライセンスは必要ですか？** 無料トライアルで評価は可能ですが、本番環境では永続ライセンスが必要です。  
- **サポートされているファイル形式は何ですか？** DOCX、XLSX、PPTX、PDF、画像形式など、30 以上の形式に対応しています。  
- **大容量ファイルを効率的に処理できますか？** はい。非同期メソッドとチャンク処理を使用すれば、最大 2 GB のファイルを扱えます。

## プログラムで赤字PDFを作成するとは何か？
プログラムで赤字PDFを作成するとは、通常 GroupDocs.Redaction のような API を介してコード上で機密テキスト、画像、メタデータを検出し、定義されたルールに従って置換または削除し、元の機密情報が含まれない新しい PDF を生成することです。この自動化手法により、大量の文書に対して一貫したコンプライアンスが確保できます。

## なぜ GroupDocs.Redaction for .NET を使用するのか？
GroupDocs.Redaction は **30 以上の入力・出力形式** に対応し、ファイル全体をメモリに読み込むことなく **2 GB** までの文書を処理できます。これにより、従来の手法と比較して **RAM 使用量を 30 %** 削減できます。また、組み込みの OCR 赤字化機能により、スキャン画像内のテキストも検索可能かつ削除可能です。

## プログラムで赤字PDFを作成する方法？

プログラムで赤字PDFを作成するには、まずソースドキュメントを `Redactor` インスタンスに読み込み、削除または置換したいテキストやパターンを示す `Redaction` オブジェクトを定義・適用し、最後に `PdfSaveOptions` を指定して `Save` メソッドを呼び出し、セキュアな PDF ファイルを生成します。以下のコードが各ステップを示しています。

### Step 1: initialize the redactor
`Redactor` はドキュメントを読み込み、処理し、保存するコアクラスであり、文書の整合性を保ちます。

```csharp
using (Redactor redactor = new Redactor("YOUR_DOCUMENT_DIRECTORY\SampleDocument.docx"))
{
    // Further operations will go here.
}
```  

**Why use Redactor?**  
`Redactor` クラスは文書処理を体系化し、メモリ管理を効率化すると同時に、フォーマット間で一貫した赤字化結果を提供します。

### Step 2: apply exact‑phrase redaction
`Redaction` オブジェクトは、隠すテキストと置換方法を定義します。

```csharp
redactor.Apply(new ExactPhraseRedaction("John Doe", new ReplacementOptions("[personal]"));
```  

**Understanding parameters and methods**  
- `"John Doe"` – 正確に検索するフレーズ。  
- `ReplacementOptions` – プレースホルダー（例: `"[personal]"`）とビジュアルスタイルを指定。

### Step 3: save as PDF
`PdfSaveOptions` は最終的な PDF 出力を制御し、画像品質やページ範囲などを設定できます。

```csharp
redactor.Save(new PdfSaveOptions());
```  

**Key configuration options**  
`PageCount`、`ImageQuality`、`CompressImages` を設定して、ファイルサイズと画質のバランスを調整できます。

## 一般的な問題と解決策

- **File‑path errors** – 入出力パスが絶対パスまたは実行ディレクトリに対して正しく相対指定されているか確認してください。  
- **Unsupported format** – 公式ドキュメントの形式リストを確認し、古い Office 形式は事前に変換が必要な場合があります。  
- **Memory spikes with large files** – 非同期 API (`Redactor.RedactAsync`) を使用し、文書をチャンク単位で処理してください。

1. **Legal document handling** – 契約書を外部顧問と共有する前に、個人識別子を自動的にマスクします。

## よくある質問

**Q: 2 GB を超える文書はどう扱えばよいですか？**  
A: ソースファイルを章ごとなど論理的なセクションに分割し、各セクションを個別に赤字化してから、結果の PDF を結合します。

**Q: 赤字化プレースホルダーのスタイルはカスタマイズできますか？**  
A: はい。`ReplacementOptions` でフォント、色、透明度などを指定できます。

**Q: GroupDocs.Redaction はスキャンした PDF の OCR 赤字化をサポートしていますか？**  
A: もちろんです。`Redactor` 作成時に `OcrOptions` を有効にすれば、画像内のテキストも検出・赤字化できます。

**Q: バッチ処理は可能ですか？**  
A: ファイルパスのコレクションをループし、同じ赤字化ロジックを並列タスクで実行すれば、数十ファイルを同時に処理できます。
