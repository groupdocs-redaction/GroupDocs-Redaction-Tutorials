Whether you need to comply with GDPR, HIPAA, or internal security policies, redacting sensitive information before sharing a PDF protects privacy and reduces legal risk. This tutorial shows you how to use **GroupDocs.Redaction for .NET** to locate, mask, and finally save a document as a secure PDF. You’ll learn how to:

Creating a redacted PDF programmatically means using code—typically through an API such as GroupDocs.Redaction—to locate confidential text, images, or metadata within a source file, replace or remove that content according to defined rules, and then generate a new PDF that no longer contains the original sensitive information. ## How to create redacted PDF programmatically?

To create a redacted PDF programmatically, first load the source document into a `Redactor` instance, then define and apply one or more `Redaction` objects that specify the text or patterns to be removed or replaced, and finally invoke the `Save` method with `PdfSaveOptions` to generate a secure PDF file. The following code illustrates each step.

### Step 1: initialize the redactor
`Redactor` is the core class that loads, processes, and saves documents while preserving document integrity.

```csharp
using (Redactor redactor = new Redactor("YOUR_DOCUMENT_DIRECTORY\\SampleDocument.docx"))
{
    // Further operations will go here.
}
```  

**Why use Redactor?**  
The `Redactor` class provides a structured way to handle documents, ensuring efficient memory management and consistent redaction results across formats.

### Step 2: apply exact‑phrase redaction
The `Redaction` object defines what text to hide and how to replace it.

```csharp
redactor.Apply(new ExactPhraseRedaction("John Doe", new ReplacementOptions("[personal]"));
```  

**Understanding parameters and methods**  
- `"John Doe"` – the exact phrase to locate.  
- `ReplacementOptions` – specifies the placeholder (e.g., `"[personal]"`) and visual style.

### Step 3: save as PDF
`PdfSaveOptions` controls the final PDF output, including image quality and page range.

```csharp
redactor.Save(new PdfSaveOptions());
```  

**Key configuration options**  
You can set `PageCount`, `ImageQuality`, and `CompressImages` to balance file size and visual fidelity.

## Common issues and solutions

- **File‑path errors** – Verify that both input and output paths are absolute or correctly relative to the executing directory.  
- **Unsupported format** – Check the format list in the official docs; older Office formats may need conversion first.  
- **Memory spikes with large files** – Use the asynchronous API (`Redactor.RedactAsync`) and process the document in chunks.

## Frequently asked questions

**Q: How do I handle documents larger than 2 GB?**  
A: Split the source file into logical sections (e.g., by chapter) and redact each section individually, then merge the resulting PDFs.

**Q: Does GroupDocs.Redaction support OCR for scanned PDFs?**
